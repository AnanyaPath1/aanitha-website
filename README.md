# A. Anitha — TOO EMOTIONAL / 01

This version deliberately changes the website language from the previous chapter.

Core idea:
- A. Anitha is a chapter-based, story-led label.

- Drops are not permanently open.

To deploy:
1. Upload the folder to GitHub.
2. Enable GitHub Pages or connect the repo to Vercel.
3. Keep the hero image in assets/hero-tee.jpeg.
4. Later replace the closed-drop CTA with your store URL.
